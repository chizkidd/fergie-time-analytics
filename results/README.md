# Historical Season Summary

The included CSV contains selected season-level descriptive statistics summarized from the original project documentation. These are descriptive diagnostics, not model-performance scores. The key features for each season are:

- `shots_per_match`: total number of shots in a season divided by total matches in that season.
- `goals_per_xg`: the ratio between total number of goals and total expected goals in a season.
- `home_points_per_match`: total number of points by the home team divided by total matches in a season.
- `last_shot_minute_mean`: the average minute when the last shot in a match happens.
- `shots_from_75` and `xg_from_75`: shots and expected goals from minute 75 onward, inclusive, per match.
- `goals_from_90`: total number of goals scored from minute 90 onward, per match.
- `subs_used_per_side`: average substitutions used by each team per match.
